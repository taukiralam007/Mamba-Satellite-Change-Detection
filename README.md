# Mamba Satellite Change Detection

Multispectral satellite change detection experiments using CNN, selective state-space, Mamba, and Transformer-based architectures.

## Current Models
- CNN-CD baseline
- Selective SSM-CD V1
- Selective SSM-CD V2
- Mamba-CD
- Transformer-CD

## Dataset
Malaysia multispectral change-detection demo data from the IHCLab/TRFL project.

## Metrics
- OA
- F1_c
- IoU_c
- Cohen's Kappa
- Inference time
